# Contributing

This is a personal GitHub profile repository, but suggestions are welcome.

## Ideas welcome

- Better DBZ-themed icons (SVGs)
- Layout tweaks that survive GitHub's HTML sanitizer
- Alt text and accessibility improvements
- Typo fixes

## How to contribute

1. Fork the repo
2. Create a branch (`git checkout -b your-change`)
3. Make focused, atomic commits
4. Open a PR against `main` with a brief description

## Style

- Follow `.editorconfig`
- Keep README HTML readable (consistent indentation)
- Icon SVGs use `viewBox="0 0 24 36"` (top-padded so `align="top"` centers the icon with text on GitHub)

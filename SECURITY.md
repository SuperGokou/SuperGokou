# Security Policy

This repository hosts the public GitHub profile README and supporting assets.
It does not contain sensitive code, but if you spot a security issue (for
example a leaked credential in commit history or a malicious dependency in
local helper scripts), please report it privately.

## Reporting a Vulnerability

Email **ming.xia@alumni.harvard.edu** with:

- A description of the issue
- Steps to reproduce
- Affected file(s) or URL(s)

Please do **not** open a public issue for security concerns until they have
been triaged.
